# Changelog

## 0.1.0 — unreleased

- Rust multilevel layout, GFA1.0–1.2 records and optional Bandage/OGDF backend.
- Faster shape-aware packing with equivalent placement order and tie-breaking.
- Cancellable loading, visible parser diagnostics, strict parsing option and gzip input.
- Saved graph sessions, recent files, remembered appearance, drag-and-drop opening,
  and bounded undo/redo for movement.
- Background, atomic SVG/PNG/FASTA/CSV exports, configurable figure size and viewport
  cropping; PNG labels and consistent segment thickness/direction indicators.
- Corrected N50/L50 for odd totals, quoted CSV fields, deterministic FASTA order,
  and keyboard shortcuts that respect text editing.
- Cached colour ranges and debounced filtering to reduce repeated UI work.
- Build/test workflows, release packaging, GPLv3 license and third-party notices.
